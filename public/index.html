germaniac

Web personal de German. Espacio para proyectos, herramientas propias y experimentos.

De qué se trata

Este sitio es el espacio para los proyectos personales de German: herramientas propias para organizar tareas, planificar el día a día y sacar más provecho del tiempo.

Es un proyecto en desarrollo: las herramientas se construyen y se mejoran de forma continua, para uso personal y privado.

Qué estás haciendo acá

  • Un mapa del sitio, con enlaces a cada página y proyecto.
  • Detalles generales sin necesidad de iniciar sesión para visitar el sitio.
  • Acceso privado a las herramientas propias desde la cuenta de Google del autor.

La web es de uso personal y privado, y no comparte información con terceros.
